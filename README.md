## 投稿注意事项
1、稿件必须为全英文稿件。
2、所有稿件应为原创，未公开见刊的，论文需要符合主题、论据充分、具备实用价值和创新性。
3、投稿的文章由评审进行评估，评估内容包括原创性、技术或研究的内容和深度、会议主题相关性、贡献性和可读性。
4、文章篇幅不少于4页,含公式图表等。
5、 作者可通过iThenticate或其他查询系统查重，重复率不得超过24%且单条引用源不得高于3%。
6. 若您的文章被录用，我们将以邮件形式通知您，您将收到以下文件：录用通知、审稿意见表、注册表、终稿确认函
7、投稿后7-10个工作日内反馈审稿意见或录用通知；
