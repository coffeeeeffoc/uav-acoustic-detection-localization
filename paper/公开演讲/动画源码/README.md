# 基于方向条件相干谱排序的无人机声学探测与测向

双击上一级的 **03 交互动画版.html** 即可现场放映。单个文件已包含 Remotion 播放器、图像、代码和样式。桌面和投影使用 16∶9 画布，窄屏竖持时图表和解读上下排列。

## 现场怎么讲

单击或轻触画布、按空格都只推进一个讲解步骤。动画停在结果上，可以一直讲到准备好再点。本页最后一步结束后，再点才进入下一页。末页停留在致谢。底栏的分数表示当前页内进度。

| 操作 | 输入 |
| --- | --- |
| 推进一步 | 画布单击、轻触、空格、Enter、→ 或 Page Down |
| 回到上一步的完成画面 | 回退、←、退格或 Page Up，可跨页 |
| 重播当前一步动画 | R，或打开提示，轻触“重播本步” |
| 章节目录 | 目录或 M，选择章节会从该章第一步开始 |
| 本章讲解提示 | 提示或 N；提示和目录也会投在屏幕上 |
| 收起弹窗 | Esc、关闭，或再次按当前面板的快捷键 |
| 首场 / 片末 | Home / End |
| 全屏投影 | 全屏或 F；浏览器支持时可用，Esc 可退出 |

打开系统的“减少动态效果”后，仍逐击揭示，直接呈现每一步的完成画面。

## 演讲顺序

| 章节 | 点击时可以指给听众看什么 |
| --- | --- |
| 论文题目 | 展示正式题名、作者和单位。单击进入第二页的问题情境。 |
| 研究背景 | 先问“听见无人机，能指出方向吗？”，再用两路声音抵达同一阵列的情形解释为什么会选错。风机和双声源情景是示意。 |
| 研究问题 | 先给出报警条件，再加入方向偏差 ≤10°，两者都成立才算联合成功。 |
| 候选方向排序 | 四个候选按峰高排列，再展开各方向 24 个频带的特征，最后追踪 B 从第二位移到第一位。频带图形和名次仅用于解释。 |
| 实验设计 | 100 m 开发；150 m、200 m 逐组保留评价。一次观测长 200 ms，同段切窗相关，无法据此推算最大探测距离。 |
| 方向偏差 | 三行比较依次保留在同一尺度上。中位数几乎重合，95 分位由 96.87° 降到 54.16°。本场与固定报警场均以采集示意图中的静态标称方向为参照，未同步跟踪无人机。 |
| 联合成功率 | 先圈定 514 个报警，再看联合成功数 459 和 513。每步分类从首帧固定，扫光指示当前讲解的真实格子。分母均为全部 600 个无人机窗，橙框标出 DCCR 唯一已报警但方向超差的窗。 |
| 误差来源 | 从 1 个已报警超差窗加 35 个未报警超差窗，得到全部 36 个超差窗。再拆成 34 个缺候选、2 个选错；按录音计数，33 个来自 200 m 组第 2 段。 |
| 研究结论 | 回看 A 与 B，再看全部无人机窗的超差数从 91 个降至 36 个。 |
| 研究展望 | 从环境适应性、动态声源测向和实时处理三个角度讨论现有结论的适用范围。 |
| 致谢 | 以“谢谢大家”结束，画面停留在此页。 |

## 构建与 Studio

需要 Node.js 和 npm。在本目录执行：

```sh
npm ci
npm run build
npm run studio
```

构建只更新上一级的离线 HTML。Studio 中打开 **AcousticsTalk**，时间线按上述顺序展示 26 个讲解状态，每个状态占 90 帧（30 fps）。HTML 中每一步独立播放，然后等待讲者操作。两者共用同一份讲解顺序和图表。

- `story.js` 保存章节、逐击标题、解读和数据出处。
- `scenes.jsx` 实现逐帧绘制的图表、换位和分组动画。
- `app.jsx` 处理逐击放映、目录、讲解提示、触摸与快捷键。
- `talk.css` 定义投影与窄屏版式，`studio.jsx` 生成预览时间线。

数据来自 Ju Luo、Yuqian Zhou《基于方向条件相干谱排序的无人机声学探测与测向》中文修订稿表 I–III 及讨论。两张 JPEG 是概念配图。
